# Paradise Nursery 🌿

## Project Name: Paradise Nursery Shopping Application

A dynamic React-based e-commerce shopping cart application for an online plant shop — **Paradise Nursery**.

## Description

Paradise Nursery is a feature-rich plant shopping application built with React and Redux Toolkit. Users can browse a curated collection of houseplants organized by category, add plants to their cart, manage quantities, and enjoy a seamless shopping experience.

## Features

- 🌱 Browse 18+ unique houseplants across 3 categories
- 🛒 Add to cart with real-time cart count updates
- ➕➖ Increase/decrease item quantities in cart
- 🗑️ Remove individual items from cart
- 💰 Live total cost calculation
- 📱 Responsive design with smooth navigation
- 🔁 Continue Shopping functionality

## Tech Stack

- **React** – UI components
- **Redux Toolkit** – State management (CartSlice)
- **React Router** – Client-side navigation
- **Vite** – Build tooling
- **CSS** – Custom styling
